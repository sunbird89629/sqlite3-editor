# Proposal

## Why

数据表格的编辑交互还有几处不连贯：单击单元格就立刻进入编辑，选中状态不可见，键盘无法在单元格之间移动；取消单元格编辑会跳到"新增记录"表单；底部编辑面板常驻且无法收起，宽表时把数据挤出视口；值类型用五个复选框表示单选；提交成功后除了面板切换没有任何确认；原生 SQL 编辑器返回的结果出现在页面最底部，只能关闭，不能复制。

## What Changes

- 单元格改为两段式：第一次点击选中（可见描边），再次点击、双击、Enter 或 F2 开始编辑；Esc 清除选中。
- 选中单元格后可用方向键在单元格间移动，跨越页边界时自动翻页；单元格可通过 Tab 聚焦。
- 取消单元格编辑时收起编辑面板，不再展示"新增记录"表单；展开后仍可继续使用。
- 编辑面板增加标题栏折叠开关，折叠后只保留标题和反馈，折叠状态不写入持久化。
- 值类型改为单选按钮组，具备单选语义与键盘操作。
- 提交成功后标题栏显示短暂的 "Saved" 反馈。
- 原生 SQL 编辑器的结果面板移到数据区、提供复制 CSV / 复制 JSON，并保留关闭。
- 修正 `ui/main.tsx` 中未使用的导入，保持类型检查干净。

## Capabilities

### New Capabilities

- `cell-editor`: 单元格编辑面板本身的行为：折叠、取消编辑、保存反馈与值类型选择。
- `sql-editor-results`: 原生 SQL 编辑器执行结果在数据区的呈现与导出操作。

### Modified Capabilities

- `data-grid-pagination`: 新增单元格选择与键盘导航要求（两段式选中、方向键移动、Enter/F2 编辑、Esc 清除）。

## Impact

- `ui/table.tsx`（选中状态、单元格交互、键盘导航接入）、`ui/editor.tsx`（折叠、取消、反馈、单选类型）、`ui/keybindings.ts`（选择导航）、`ui/main.tsx`（结果面板）、`ui/style.scss`。
- 现有测试中"单击即编辑"的写法需要改为两次点击；新增 `ui/tests/viewer_selection.spec.ts` 覆盖选中、键盘、折叠、反馈与单选类型。
