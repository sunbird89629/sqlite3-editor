# Spec Delta

## MODIFIED Requirements

### Requirement: 只读查询模式与表格模式互斥

数据区 SHALL 在「表格」和「自定义查询」两种模式之间切换，同一时刻只显示其中一种内容；模式开关 SHALL 始终可见，并标出当前模式。进入查询模式时，表选择器、新增记录入口与可写的编辑面板 SHALL 隐藏，查询输入只保留只读查询框。

#### Scenario: 进入查询模式
- **WHEN** 用户从表格模式切换到自定义查询模式
- **THEN** 数据区不再显示表格记录，改为显示查询编辑器，输入框获得焦点，可写编辑面板隐藏

#### Scenario: 返回表格模式
- **WHEN** 用户在查询模式下切回表格模式
- **THEN** 数据区恢复显示当前表的记录，并保持原来的表、排序和筛选
